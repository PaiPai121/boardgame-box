# 桌游盒子

十款桌游与棋类游戏的浏览器合集，支持一档简单电脑、多人同屏、动作动画和本机存档。

**游玩地址：[打开桌游盒子](https://paipai121.github.io/boardgame-box/)**

## 包含游戏

- 璀璨宝石：宝可梦
- 璀璨宝石：原版
- 七大奇迹（可玩预览）
- 波多黎各（经典基础版及双人规则）
- 围棋、五子棋、象棋、国际象棋
- 圈套棋 YINSH（标准三环／快速一环）
- 勃艮第城堡（2011 经典基础规则 · 1 号标准领地）

在 Windows、macOS、iPad 或 Android 的现代浏览器中打开即可游玩。多人同屏时，朋友轮流操作同一台设备；可与简单电脑混合组局。完整载入后会缓存游戏与素材，可离线访问。

存档保存在当前浏览器，清除网站数据会删除存档，不会跨设备同步。此站点采用静态托管；各自设备的房间联机需要另行运行房间服务。

## 版本

`0.9.0-preview.7-pages.1`，单机／同屏版。

新增勃艮第城堡：支持 2–4 人、真人与一档简单电脑混合。五个阶段、每阶段五轮；双骰行动、工人调点、六个货站和黑市、全部 8 种建筑与 26 种知识。城堡、市政厅、仓库等有明确连锁步骤；暂存满时可选择替换，双骰用完后仍可购买，再结束回合。船舶收货含货仓容量和相邻货站选择，顺序在下一轮生效。当前开放 1 号标准领地与中央起始城堡；其他编号领地及扩展尚未开放。

勃艮第城堡可查看所有玩家的领地、暂存、已建地块、知识与逐笔得分，含规模分、阶段分、颜色奖励、畜牧重复计分及终局知识/资源明细。不可操作的控件支持悬停、键盘聚焦与触屏点击说明原因。包含地块飞行与落地、骰子翻滚、资源变化和区域完成动画，支持全局动效开关。101 张本地素材含 37 个出版商规则书原始图片对象，来源与 SHA-256 随站点保留；部分原图分辨率较低，中文效果另行清楚展示。

规则参照[发行方经典说明书](https://cdn.1j1ju.com/medias/04/f5/f9-the-castles-of-burgundy-rulebook.pdf)与[授权线上版勘误](https://www.yucata.de/en/Rules/CastlesOfBurgundy)，采用经典知识 15／26 的 3／2 分，不混用 2019 版。45 场规则对局覆盖所有知识，成品通过实际按钮完整 25 轮、触屏提示、动画、电脑回应、自动存档及 320／390／768／1024 宽度布局检查；模拟浏览器检查未替代实体设备检查。

新增圈套棋：85 个交点、五环开局、移环留子、跳跃翻色、连续五子收排和收环得分。支持一档简单电脑、双人同屏、白黑执子、标准或快速目标、悔棋、自动存档及离线访问。提供落点与翻色预览、环移动／棋子翻面／收回动画；按官方规则处理交叉排、多排、双方同时成排和最后一枚公共棋子。

七大奇迹可点击任意玩家的“建筑 N · 查看”查看全部已建牌，按七种类型筛选，包含卡图、中文效果、图标和该玩家的连锁状态。文明概览分别显示全部产能与可供邻座购买的产能，并展示科技、军力、贸易优惠；“奇迹 X/Y”展示完整 A/B 面阶段进度。详情可切换所有文明并在电脑结算后自动更新。

七大奇迹可点击各文明的“分 · 明细”查看七类得分的具体来源、计算公式、科技最优分配和邻座计数；终局分类表也支持逐项查看。新对局的军事明细按时代和邻座记录，旧存档保留原有实际分数。

围棋新增可开关的实时形势估算，支持 9、13、19 路：显示双方估算目数、领先差与黑白地盘标记，落子、提子、悔棋后自动刷新。中盘结果为粗略估算，复杂死活须在终局数子时确认。

七大奇迹的前置与解锁建筑提示包含 24 种原版连锁图标，可悬停、键盘聚焦或触屏点按查看解释。发布文件采用内容指纹地址，更新后保留当前浏览器的原有存档。

七大奇迹的逐牌数值尚未全部与实体第二版核对；部分棋类赛事规则和原生移动安装包仍未包含。素材来源记录随游戏文件保存在 `site/assets/` 下对应的 `art-sources.json` 和 `icon-sources.json`；这是非官方电子版。

## 发布

`site/` 是已经构建的网页运行文件。推送到 `main` 后，GitHub Actions 自动将该目录发布到 GitHub Pages。网站所有游戏、规则计算与电脑策略都在浏览器运行。
