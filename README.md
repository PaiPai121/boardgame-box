# 桌游盒子

八款桌游与棋类游戏的浏览器合集，支持一档简单电脑、多人同屏、动作动画和本机存档。

**游玩地址：[打开桌游盒子](https://paipai121.github.io/boardgame-box/)**

## 包含游戏

- 璀璨宝石：宝可梦
- 璀璨宝石：原版
- 七大奇迹（可玩预览）
- 波多黎各（经典基础版及双人规则）
- 围棋、五子棋、象棋、国际象棋

在 Windows、macOS、iPad 或 Android 的现代浏览器中打开即可游玩。多人同屏时，朋友轮流操作同一台设备；可与简单电脑混合组局。完整载入后会缓存游戏与素材，可离线访问。

存档保存在当前浏览器，清除网站数据会删除存档，不会跨设备同步。此站点采用静态托管；各自设备的房间联机需要另行运行房间服务。

## 版本

`0.9.0-preview.1-pages.1`，单机／同屏版。

七大奇迹的逐牌数值尚未全部与实体第二版核对；部分棋类赛事规则和原生移动安装包仍未包含。素材来源记录随游戏文件保存在 `site/assets/` 下对应的 `art-sources.json` 和 `icon-sources.json`；这是非官方电子版。

## 发布

`site/` 是已经构建的网页运行文件。推送到 `main` 后，GitHub Actions 自动将该目录发布到 GitHub Pages。网站所有游戏、规则计算与电脑策略都在浏览器运行。
